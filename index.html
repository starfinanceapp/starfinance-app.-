MCP server

One URL connects any MCP client to StarFinance. HTTP Streamable transport, no SDK.

Server URL

URL
https://api.starfinance.example/agent/mcp

Client configuration

Most clients accept a configuration like this. Field names vary between clients, so check your client’s documentation.

JSON
{
  "mcpServers": {
    "starfinance": {
      "url": "https://api.starfinance.example/agent/mcp",
      "headers": { "Authorization": "Bearer YOUR_STARFINANCE_KEY" }
    }
  }
}

Skills · MCP server

Give your agent every market.

Pick your agent, add one connection, and let it research and trade through StarFinance.

In your connector settings, add a custom connector and paste the server URL. Sign in or use your StarFinance key when asked.

Server URL
https://api.starfinance.example/agent/mcp

HTTP Streamable transport. Works with any MCP client.

In ChatGPT’s connector settings, add a custom MCP server with this URL. Availability depends on your plan.

Server URL
https://api.starfinance.example/agent/mcp

Add this to your .cursor/mcp.json and replace the key with yours.

JSON
{
  "mcpServers": {
    "starfinance": {
      "url": "https://api.starfinance.example/agent/mcp",
      "headers": { "Authorization": "Bearer YOUR_STARFINANCE_KEY" }
    }
  }
}

For Claude Code, run this command, then check the connection with claude mcp list.

Terminal
claude mcp add --transport http starfinance https://api.starfinance.example/agent/mcp --header "Authorization: Bearer YOUR_STARFINANCE_KEY"
